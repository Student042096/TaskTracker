# Требования к производительности к будущей версии TaskTracker

## 1. Загрузка данных

Приложение не должно загружать большой объём данных, которые пользователь не использует.

## 2. Большие списки

Для большого количества задач нужно использовать постраничную или постепенную загрузку данных.

## 3. Клиентский Javascript

Следует избегать длительных вычислений, блокирующих пользовательский интерфейс.

## 4. Медиа и вложения

Тяжелые вложения и изображения необходимо загружать только по запросу.

## 5. Работа на слабых компьютерах

Интерфейс должен быть оставаться работоспособным на компьютерах с ограниченных объёмом оперативной памяти.

## 6. Проверка производительности

- Запросы должны обрабатываться достаточно быстро.
- Если какой запрос зависает, то его прерываем и сообщаем об ошибке.
- Обновление данных на странице должны быть сделаны только в том случае, если произошло обновление данных.
- Перед обновление должно быть предупеждение сервера.
- Функции Javascript должны быть маленькими и выполнять только одну задачу.
- Обработка сложных вычислений должна производиться на сервере.
- Запросы должны быть ёмкими.
