# Руководство пользователя TaskTracker 1.3

Дата обновления: 11.10.2026

## Назначение программы
Данная программа позволяет отслеживать текущие задачи, которые были запланированы.

## Запуск
0. Для запуска установите .NET 8 SDK
1. Откройте папку `src/TaskTracker`.
2. Выполните `dotnet build`
2. Выполните `dotnet run`.

## Основные возможности
Данная программа позволяет составить список задач.
Их можно добавлять и удалять.
Также можно их изменять. Например, изменить имя или статус.

## Порядок работы
Для введения новых задач, а также их удаления можно отредактировать data/tasks.json.
Затем можно показать значения, запустив программу в консоли.

## Ограничения
Программа пока не умеет работать с редакированием. Изменение и удаление пока не реализованы.
