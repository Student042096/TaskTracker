# Требования к будующей веб-версии TaskTracker

## 1. Поддержваемая среда

Веб-интерфейс должен корректно работать как минимум в средах Firefox и современных Chromium-браузерах.
По возможности затрагивать более старые браузеры, а также браузеры на других движках.

## 2. Работа со вкладками

- Пользователь может открыть приложение в нескольких вкладках.
- Основнын данные не должны теряться при случайном закрытии вкладки.
- Интерфейс не должен зависеть от особенной группировки вкладок в браузере.
- Сохранение данных в одной из вкладок должно влечь изменения в других вкладках.

## 3. Всплывающие окна

Критические функции приложения не должны работать только через автоматически всплывающие окна, так как чаще всего браузер их блокирует.
Автоматически всплыващие окна можно использовать для вывода справки.

## 4. Cookies

- Используйте Cookies, где это действительно необходимо.
- Необходимо корректно обрабатывать завершение или прерывание пользовательской сессии
- Не делать функции зависимыми от стронних cookies.
- Cookies не должны хранить личные данные и пароли.

## 5. Авторизация

Форма входа должна быть понятна и совместима с менеджером паролей.
Необходимо добавить проверку на сложный пароль.

## 6. Разрешения браузера

Приложение не должно запраживать камеру, геолокацию или микрофон без необходимости.
Отказ от необязательного разрешения не должно блокировать работу основной функциональности приложения.
При завершении использования какой-либо функциональности уведомлять браузер.
Геолокацию использовать только в том случае, если нужно отметить точку события.
